# 데이터베이스 정규화

## 한눈에 보기

정규화는 데이터 중복과 삽입·갱신·삭제 이상을 줄이도록 테이블을 분해하고 데이터 종속성을 정리하는 과정이다.

## 오늘 학습 범위

| 단계 | 확인할 핵심 질문 |
| --- | --- |
| 제1정규형 | 각 속성 값이 원자적인가? 반복되는 값 묶음이 있는가? |
| 제2정규형 | 복합 키의 일부에만 종속되는 일반 속성이 있는가? |
| 제3정규형 | 기본 키가 아닌 속성이 다른 일반 속성을 결정하는가? |

## 영상 시청 후 정리할 내용

- 정규화 전 테이블에서 발생하는 중복
- 삽입·갱신·삭제 이상을 각각 보여주는 예시
- 함수 종속, 부분 함수 종속, 이행 함수 종속
- 1NF에서 3NF까지 테이블이 분리되는 과정
- 질문·답변 PBL의 테이블 설계에 적용할 수 있는 부분

## 관련 개념

- 기본 키와 후보 키
- 외래 키
- 함수 종속
