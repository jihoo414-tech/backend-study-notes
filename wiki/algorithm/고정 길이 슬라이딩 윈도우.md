# 고정 길이 슬라이딩 윈도우

## 한눈에 보기

슬라이딩 윈도우는 연속된 구간이 한 칸 이동할 때 **빠지는 값 하나와 들어오는 값 하나만 반영해 다음 구간의 결과를 갱신**하는 방법이다.

길이가 `K`로 고정된 연속 구간의 합을 모두 비교할 때 첫 구간의 합만 직접 구하고, 이후에는 다음 식을 사용한다.

```text
새 구간 합 = 이전 구간 합 - 창에서 빠지는 값 + 새로 들어오는 값
```

## 언제 떠올리는가

다음 표현이 함께 등장하면 고정 길이 슬라이딩 윈도우를 우선 검토한다.

- `연속된 K개`, `연속된 K일`, `고정 길이 구간`
- 모든 구간의 합·평균·개수·최댓값 등을 비교
- 인접한 두 구간이 원소 대부분을 공유
- 이전 구간의 결과에서 빠지는 값과 들어오는 값만으로 다음 결과를 계산 가능

단순히 “기간이 나온다”는 이유만으로 선택하지 않는다. 기간이 연속적이고 길이가 고정되어 있으며, 구간 집계값을 증분 갱신할 수 있는지가 핵심이다.

## 단순 풀이와의 차이

각 시작 위치마다 `K`개를 다시 더하면 창은 `N - K + 1`개이므로 시간 복잡도는 다음과 같다.

```text
O((N - K + 1) × K) = O(NK)
```

최악의 경우 `N = 100,000`이고 `K`도 `N`에 비례하면 반복 횟수가 매우 커진다. 슬라이딩 윈도우는 겹치는 `K - 1`개 원소를 다시 더하지 않아 `O(N)`으로 줄인다.

슬라이딩 윈도우만 가능한 것은 아니다. 누적 합을 만들고 각 구간 합을 빼기로 구해도 `O(N)`이지만, 누적 합 배열을 저장하면 `O(N)`의 추가 공간이 필요하다. 합만 구하는 이 문제에서는 슬라이딩 윈도우가 더 직접적이고 보조 공간도 적다.

## 동작 원리

배열이 다음과 같고 `K = 3`이라고 하자.

```text
[12, 15, 11, 20, 25, 10, 20, 19, 13, 15]
```

첫 구간 합은 `12 + 15 + 11 = 38`이다. 창을 한 칸씩 이동하면 다음과 같이 갱신한다.

| 새 인덱스 `i` | 빠지는 값 `arr[i-K]` | 들어오는 값 `arr[i]` | 새 구간 합 |
| --- | --- | --- | --- |
| 3 | 12 | 20 | `38 - 12 + 20 = 46` |
| 4 | 15 | 25 | `46 - 15 + 25 = 56` |
| 5 | 11 | 10 | `56 - 11 + 10 = 55` |

각 이동을 `O(1)`에 처리하면서 가장 큰 합 `56`을 유지한다.

## 반복문의 불변식

두 번째 반복문에서 인덱스 `i`의 갱신을 마친 직후에는 다음이 항상 성립한다.

> `windowSum`은 `arr[i-K+1]`부터 `arr[i]`까지 정확히 `K`개 원소의 합이고, `maxSum`은 지금까지 확인한 모든 길이 `K` 구간 합의 최댓값이다.

이 불변식을 설명할 수 있으면 `arr[i] - arr[i-K]`에서 어떤 값이 들어오고 빠지는지 암기에 의존하지 않아도 된다.

## 사용자 코드의 구조

사용자 코드는 먼저 첫 `K`개를 더한 뒤 다음 갱신식을 적용한다.

```java
answer = answer + arr[i] - arr[i - k];
```

알고리즘은 올바르지만 `answer`는 최종 답보다 현재 구간 합을 의미하므로 `windowSum`처럼 역할이 드러나는 이름이 더 명확하다.

```java
static int solution(int n, int k, int[] arr) {
    int windowSum = 0;
    for (int i = 0; i < k; i++) {
        windowSum += arr[i];
    }

    int maxSum = windowSum;
    for (int i = k; i < n; i++) {
        windowSum += arr[i] - arr[i - k];
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}
```

## 복잡도와 자료형

- 시간 복잡도: `O(N)`
- 현재 구현의 전체 공간 복잡도: 입력 배열을 저장하므로 `O(N)`
- 입력 배열을 제외한 알고리즘의 보조 공간: `O(1)`

문제 조건에서 최댓값은 `100,000 × 500 = 50,000,000`이므로 Java `int` 범위 안에 있다. 합의 상한이 더 큰 문제라면 `long`을 사용해야 한다.

## 경계 조건

- `K = N`: 첫 구간이 유일한 구간이며 두 번째 반복문은 실행되지 않는다.
- `K = 1`: 일반적인 슬라이딩 윈도우 코드는 동작하지만 이 문제 조건은 `K >= 2`다.
- 음수가 포함된 입력: `maxSum`을 첫 구간 합으로 초기화하면 그대로 동작한다. `0`으로 초기화하면 모든 구간 합이 음수일 때 잘못될 수 있다.
- `K > N`: 문제 조건에서는 발생하지 않지만 일반 함수라면 사전 검증이 필요하다.
