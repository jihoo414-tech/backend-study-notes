# 문자열 순회와 변환 패턴

## 한눈에 보기

문자열 문제 세 개에서 재사용할 수 있는 핵심은 다음과 같다.

| 문제 유형 | 핵심 패턴 | 순회 중 유지할 상태 |
| --- | --- | --- |
| 가장 가까운 문자 거리 | 왼쪽·오른쪽 양방향 탐색 | 마지막으로 본 대상 문자와의 거리 |
| 연속 문자열 압축 | 같은 문자의 연속 구간 세기 | 현재 문자와 반복 횟수 |
| 암호 해석 | 고정 길이 분할과 진법 변환 | 현재 7자리 묶음과 변환 결과 |

세 문제 모두 문자열을 무작정 여러 번 잘라 비교하기보다, **한 위치를 읽을 때 무엇을 기억할지** 정하는 것이 중요하다.

## 왜 필요한가

문자열 문제는 입력 형태가 달라도 순차 탐색, 구간 경계 처리와 문자 변환이 반복해서 등장한다. 문제별 코드를 외우기보다 다음 질문으로 접근하면 풀이를 단순화할 수 있다.

- 왼쪽에서 오른쪽으로 읽을 때 필요한 이전 정보는 무엇인가?
- 반대 방향 정보도 필요한가?
- 같은 상태가 끝나는 경계는 언제인가?
- 입력을 몇 글자씩 하나의 단위로 해석해야 하는가?

## 핵심 개념

### 양방향 탐색으로 최소 거리 구하기

한 방향으로만 순회하면 현재 위치의 왼쪽에 있는 대상 문자까지의 거리만 알 수 있다. 오른쪽에 더 가까운 대상 문자가 있을 수 있으므로 두 방향의 결과를 결합한다.

```text
왼쪽 → 오른쪽: 가장 가까운 왼쪽 대상까지의 거리 기록
오른쪽 → 왼쪽: 가장 가까운 오른쪽 대상까지의 거리와 기존 값 중 최솟값 선택
```

각 위치를 두 번만 확인하므로 문자열 길이를 `n`이라 할 때 시간 복잡도는 `O(n)`, 결과 배열을 포함한 추가 공간은 `O(n)`이다.

초기 거리는 문자열 최대 길이보다 큰 값으로 둔다. 대상 문자를 만나면 거리를 `0`으로 초기화하고, 그렇지 않으면 이전 거리에서 `1`을 더한다.

### 연속 구간을 세어 문자열 압축하기

문자열 압축은 같은 문자가 **전체 문자열에 몇 번 나오는지**가 아니라 **연속해서 몇 번 나오는지**를 센다.

```text
현재 문자와 다음 문자가 같음   → 반복 횟수 증가
현재 문자와 다음 문자가 다름   → 현재 문자와 횟수 출력 후 새 구간 시작
문자열 끝에 도달              → 마지막 구간 출력
```

반복 횟수가 `1`이면 숫자를 생략한다. 가장 자주 생기는 실수는 문자가 바뀔 때만 결과를 추가하고 마지막 연속 구간을 빠뜨리는 것이다. 루프가 끝난 뒤 마지막 구간을 처리하거나, 종료 조건을 동일하게 처리할 방법을 정해야 한다.

시간 복잡도는 `O(n)`이다. 결과를 반복 연결해야 한다면 가변 문자열인 `StringBuilder`를 사용해 의도를 드러낼 수 있다.

### 고정 길이 분할과 진법 변환

문자 하나가 정확히 7개의 신호로 표현되므로 전체 문자열을 7자리씩 나눈다.

```text
7자리 추출 → '#'을 '1'로 변환 → '*'를 '0'으로 변환
→ 2진 문자열을 정수로 변환 → 정숫값을 문자로 변환
```

Java에서는 `substring(begin, end)`의 시작 인덱스는 포함하고 끝 인덱스는 포함하지 않는다. `i`번째 문자 묶음의 범위는 `i * 7`부터 `(i + 1) * 7` 직전까지다.

`Integer.parseInt(binary, 2)`는 문자열을 2진수로 해석한다. 문제에서 변환 결과가 대문자 ASCII 범위임을 보장하므로 얻은 정수를 `char`로 변환할 수 있다.

문자열을 만들지 않고 왼쪽부터 다음 계산을 반복해도 같은 진법 변환이 된다.

```text
value = value * 2 + 현재 비트
```

## 동작 원리

세 문제의 공통 구조는 다음과 같다.

```text
입력의 처리 단위를 정한다
→ 순회 방향을 정한다
→ 다음 위치로 넘겨야 할 최소 상태를 정한다
→ 상태가 바뀌는 경계에서 결과를 확정한다
→ 마지막 경계를 별도로 확인한다
```

## 예제

### 양방향 거리

`teachermode`에서 `e`를 찾을 때 왼쪽 순회 결과만 사용하면 오른쪽에 있는 더 가까운 `e`를 놓칠 수 있다. 반대 방향으로 다시 순회하며 두 거리 중 작은 값을 선택해야 한다.

### 연속 구간

`KKHSSSSSSSE`는 다음 연속 구간으로 나뉜다.

```text
KK | H | SSSSSSS | E
```

각 구간의 문자와 길이를 사용하며 길이가 1인 구간의 숫자는 생략한다.

### 7자리 암호

```text
#*****# → 1000001(2) → 65(10) → 'A'
```

## 주의사항

- 최소 거리 문제에서 대상 문자가 입력에 반드시 존재하는지는 문제 조건을 확인한다.
- 압축 문제에서는 떨어져 있는 같은 문자를 하나의 그룹으로 합치지 않는다.
- 문자열 끝은 하나의 구간 경계다. 마지막 그룹의 출력 누락을 확인한다.
- `substring(begin, end)`의 `end`는 포함되지 않는다.
- 암호 문자열 길이가 문자 개수의 7배인지 확인하면 인덱스 오류를 예방할 수 있다.
- Java의 `charAt()` 인덱스는 `0`부터 `length() - 1`까지다.
