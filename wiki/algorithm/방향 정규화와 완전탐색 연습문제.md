# 방향 정규화와 완전탐색 연습문제

## 목적

[회전 가능한 직사각형의 방향 정규화](%ED%9A%8C%EC%A0%84%20%EA%B0%80%EB%8A%A5%ED%95%9C%20%EC%A7%81%EC%82%AC%EA%B0%81%ED%98%95%EC%9D%98%20%EB%B0%A9%ED%96%A5%20%EC%A0%95%EA%B7%9C%ED%99%94.md)에서 사용한 사고 과정을 단계적으로 연습한다.

```text
가능한 선택을 정의한다
→ 입력 제한으로 탐색 가능한 크기인지 판단한다
→ 대칭·중복·독립성을 찾아 후보를 줄인다
→ 정규화할 수 있으면 표준 상태로 바꾼다
→ 줄일 수 없는 경우에만 조합·순서를 실제로 탐색한다
```

이 목록의 모든 문제가 최소직사각형과 같은 코드를 사용하는 것은 아니다. `바탕화면 정리`는 최소 경계 집계가 직접적으로 닮았고, 나머지는 완전탐색에서 후보 공간을 정의하고 줄이는 사고를 비교하기 위해 선택했다.

프로그래머스의 [완전탐색 고득점 Kit](https://school.programmers.co.kr/learn/courses/30/parts/12230)에서도 최소직사각형과 함께 모의고사·소수 찾기·카펫·피로도·전력망을 둘로 나누기를 완전탐색 문제로 분류한다.

## 1. 바탕화면 정리

### 연습할 발상

- 모든 파일을 포함하는 가장 작은 축 정렬 직사각형을 구한다.
- 각 파일 위치를 볼 때 네 경계 중 어떤 값을 갱신해야 하는지 생각한다.
- 격자 **칸**의 위치와 드래그 **격자점** 좌표가 왜 1 차이 나는지 구분한다.

### 풀기 전 질문

1. 파일 하나를 발견했을 때 위·아래·왼쪽·오른쪽 경계에 어떤 영향을 주는가?
2. 모든 드래그 시작점과 끝점을 조합으로 만들 필요가 있는가?
3. 최소직사각형의 `maxLong`, `maxShort` 집계와 무엇이 같고 무엇이 다른가?

## 2. 모의고사

### 연습할 발상

- 후보가 세 명으로 고정되어 있으므로 모든 후보의 결과를 직접 계산한다.
- 반복 패턴은 문제 번호를 패턴 길이로 나눈 나머지로 표현할 수 있다.
- 최고 점수 동점 후보를 빠뜨리지 않고 집계한다.

### 풀기 전 질문

1. 이 문제에서 완전탐색하는 후보는 무엇인가?
2. 후보 수가 입력 크기와 함께 증가하는가, 고정되어 있는가?
3. 각 패턴을 끝없이 생성하지 않고 필요한 위치의 값만 얻을 수 있는가?

## 3. 카펫

### 연습할 발상

- 전체 격자 수를 만족하는 가능한 가로·세로 쌍만 후보로 만든다.
- `(가로, 세로)`와 `(세로, 가로)`의 대칭 중 한쪽만 검사한다.
- 후보를 찾은 뒤 테두리와 내부 격자 조건을 함께 검증한다.

### 풀기 전 질문

1. 전체 격자 수를 알 때 가로·세로 후보는 어떤 수학적 관계를 만족하는가?
2. 문제의 `가로 >= 세로` 조건은 어떤 중복 후보를 제거하는가?
3. 넓이만 같은 직사각형 중 정답을 구분하는 추가 조건은 무엇인가?

## 4. 소수 찾기

### 연습할 발상

- 일부 또는 모든 숫자 조각을 사용해 만들 수 있는 순서를 탐색한다.
- 같은 숫자가 여러 경로에서 만들어질 수 있으므로 생성 결과의 중복을 제거한다.
- 숫자 생성과 소수 판정을 서로 다른 책임으로 나눈다.

### 풀기 전 질문

1. 선택 여부뿐 아니라 선택 순서도 결과를 바꾸는가?
2. `0`, 중복 숫자와 같은 입력이 같은 정수를 여러 번 만드는 경우는 무엇인가?
3. 최소직사각형처럼 각 입력을 독립적으로 정규화할 수 없는 이유는 무엇인가?

## 5. 피로도

### 연습할 발상

- 먼저 방문한 던전이 남은 피로도를 바꾸므로 순서가 중요하다.
- 던전 수가 최대 8이라는 제한이 순열 탐색 가능성을 알려준다.
- 현재 피로도로 방문할 수 없는 경로는 더 탐색하지 않는다.

### 풀기 전 질문

1. 현재 선택이 다음 선택 가능 여부에 어떤 영향을 주는가?
2. 정렬 규칙 하나만으로 항상 최적 순서를 보장할 수 있는가?
3. 재귀 상태에는 현재 피로도, 방문 여부와 방문 수 중 무엇이 필요한가?

## 6. 전력망을 둘로 나누기

### 연습할 발상

- 가능한 모든 전선 하나를 끊어보는 후보 열거와, 끊은 뒤 한쪽 전력망의 크기를 세는 그래프 탐색을 분리한다.
- 송전탑이 `N`개인 트리에는 전선이 `N-1`개라는 조건을 활용한다.
- 한쪽 크기가 `count`라면 다른 쪽은 `N-count`로 바로 계산한다.

### 풀기 전 질문

1. 이 문제에서 완전탐색할 대상은 송전탑인가, 전선인가?
2. 전선 하나를 끊은 뒤 결과를 어떻게 검증할 것인가?
3. 두 전력망을 각각 다시 탐색하지 않고 한쪽 크기만으로 차이를 구할 수 있는가?

## 문제별 기록 규칙

각 문제를 풀 때 코드보다 먼저 다음 표를 작성한다.

| 기록 항목 | 작성할 내용 |
| --- | --- |
| 탐색 후보 | 무엇을 하나씩 모두 확인하는가? |
| 경우의 수 | 입력 제한에서 최대 몇 개인가? |
| 중복·대칭 | 같은 결과를 만드는 후보가 있는가? |
| 정규화 | 후보를 표준 상태 하나로 바꿀 수 있는가? |
| 조기 종료 | 더 볼 필요가 없는 조건은 무엇인가? |
| 복잡도 | 후보 수와 후보 하나의 검증 비용은 얼마인가? |
