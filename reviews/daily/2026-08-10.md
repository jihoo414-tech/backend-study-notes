# 2026-08-10 학습 정리

## 오늘 배운 내용

- HTTP 멱등성은 동일한 요청을 여러 번 수행해도 서버에 대한 의도된 효과가 한 번 수행했을 때와 같은 성질이다.
- 멱등성은 응답 본문이나 상태 코드가 매번 완전히 같다는 뜻이 아니다. `DELETE`는 첫 요청과 이후 요청의 응답이 달라도 최종 삭제 상태가 같으므로 멱등할 수 있다.
- `GET`은 명세상 멱등하지만, `POST`는 같은 요청마다 새 리소스나 추가 효과를 만들 수 있어 멱등성이 보장되지 않는다.
- 프론트엔드 검증은 빠른 사용자 피드백을 제공하지만 우회할 수 있으므로, 백엔드가 요청 데이터를 다시 검증하고 실패 결과를 오류 응답으로 반환해야 한다.
- Spring MVC에서는 `@Valid` 또는 `@Validated`로 검증을 실행하고, DTO의 `@NotBlank`, `@Size` 같은 제약 조건으로 입력 규칙을 선언할 수 있다.
- 프로그래머스의 쉬운 `SELECT` 문제 6개를 풀며 `ROUND()`, 복수 컬럼 `ORDER BY`, `BETWEEN`, `CASE`를 연습했다.
- `ORDER BY`에 여러 컬럼을 지정하면 왼쪽 컬럼부터 우선 정렬하고, 앞선 기준의 값이 같은 행에 다음 기준을 적용한다.
- `BETWEEN`은 시작값과 끝값을 모두 포함하며, `CASE`는 조건에 따라 조회 결과에 표시할 값을 정할 수 있다.
- 문자열의 각 위치에서 가장 가까운 특정 문자의 거리는 왼쪽과 오른쪽을 각각 순회하고 두 결과 중 작은 값을 선택해 구할 수 있다.
- 연속 문자열 압축은 현재 문자와 반복 횟수를 상태로 유지하고, 문자가 바뀌거나 문자열이 끝나는 경계에서 결과를 확정한다.
- 고정 길이 암호는 7자리씩 분할하고 `#`과 `*`을 비트로 바꾼 뒤 2진수, 정수, 문자 순서로 변환할 수 있다.
- 에라토스테네스의 체는 배열에 소수의 배수를 합성수로 표시하여 `1`부터 `N`까지의 소수 개수를 효율적으로 구한다.
- PBL `mission-01-java-string-utils`를 완료하고 `replaceAll("\\s+", ...)`로 연속된 정규식 공백 문자 묶음을 치환하는 방법을 학습했다.
- `isEmpty()`는 문자열 길이가 `0`인지 확인하고, `isBlank()`는 비어 있거나 공백으로만 이루어진 문자열인지 확인한다.

## 핵심 개념 연결

```text
네트워크 오류 → 동일 요청 재시도 → 멱등한 요청이면 의도된 서버 상태 유지
                                 → 멱등하지 않으면 중복 생성·처리 가능
```

```text
클라이언트 요청 → DTO 변환 → Bean Validation → 성공 시 비즈니스 로직
                                          → 실패 시 4xx 오류 응답
```

## 기존 지식과의 연결

- HTTP 메서드는 단순히 CRUD 이름을 대응하는 데서 끝나지 않고 안전성, 멱등성과 재시도 가능성을 함께 고려해 선택해야 한다.
- Bean Validation은 Spring MVC 요청 처리의 입구에서 형식과 범위를 검사한다. 데이터베이스 조회가 필요한 중복 확인이나 도메인 상태 판단은 별도의 비즈니스 규칙으로 구분해야 한다.
- 백엔드 검증 결과를 구조화하면 프론트엔드는 필드별 오류를 사용자에게 다시 표시할 수 있다.
- SQL에서는 `WHERE`로 행을 고른 뒤 `SELECT`의 `ROUND()`와 `CASE`로 출력값을 만들고, `ORDER BY`로 최종 결과의 순서를 정한다는 흐름으로 네 문법을 연결할 수 있다.
- 문자열 세 문제는 각각 달라 보이지만 순회 중 필요한 최소 상태와 결과를 확정할 경계를 정하는 문제로 연결된다.
- 에라토스테네스의 체는 배열 인덱스를 자연수에 대응시키고, 해당 위치에 합성수 여부를 기록하는 상태 표시 기법이다.
- Java 문자열의 공백 판별은 [Spring Bean Validation](../../wiki/spring/Spring%20Bean%20Validation.md)의 입력 검증과 연결된다. 공백 전용 값을 허용할지에 따라 `isEmpty()`와 `isBlank()` 중 필요한 의미가 달라진다.

- 검증 실패를 처리하는 `BindingResult`, `@ControllerAdvice` 또는 예외 처리 코드
- `POST` 중복 요청을 방지하는 정책이 수업 프로젝트에 있는지
